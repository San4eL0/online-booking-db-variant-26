## Описание предметной области

Проект представляет собой реляционную базу данных для системы онлайн-записи в ателье по пошиву и ремонту одежды. База данных предназначена для хранения информации о клиентах, швеях, заказах, этапах выполнения работ и используемой фурнитуре.

### Основные бизнес-правила

Каждый заказ характеризуется типом ткани и сложностью работы от 1 до 5. Швеи имеют разряды от 1 до 6. Заказ сложностью выше 3 не может быть назначен швее с разрядом 2 или ниже. Для каждого заказа ведётся журнал этапов: раскрой, примерка, пошив, финиш. Ведётся учёт фурнитуры с контролем остатков. Система выявляет заказы, застрявшие на одном этапе более трёх дней.

## Структура репозитория

В корне репозитория находится файл README.md с описанием проекта, файл .gitignore для исключения временных файлов и файл answer_question_26_variant_26.md с ответом на контрольный вопрос. Папка sql содержит файл schema_variant26.sql с полным SQL-скриптом создания базы данных, таблиц, ограничений, триггера и индексов. Папка docs содержит отчёт в форматах PDF и DOCX, а также подпапку images со скриншотами результатов выполнения запросов и ER-диаграммой. Папка queries содержит три отдельных файла с запросами. Папка diagrams содержит файл ER-диаграммы в формате draw.io.
